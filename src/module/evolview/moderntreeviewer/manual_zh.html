现代化树形视图

交互式可视化和操作进化树。支持多种树形布局、颜色配置和图形标注，以及 Newick 和叶信息 TSV 导出。

1. 快速开始

  1. 点击 示例 查看示例输入数据
  2. 点击 执行 查看可视化结果
  3. 使用左侧控制面板调整显示选项

示例数据与来源（12 例）

Example 依次提供教学树、真实研究树和合成演示树。每例的 VOICE 参数注释均注明来源、用途及必要的单位说明。

示例数据来源与解释
1-3：类人猿、灵长类、哺乳动物本仓库既有教学数据，分别来自原 VOICE4MTV 示例、绘图测试资源 test.tree.txt 第 2 行和 docs/spiral.layout.tree.nwk。它们没有可核实的研究文献来源；类人猿年代仅作示意，哺乳动物枝长不作为校准年代。
4：鸟类目级树（23 叶）来自 ape::bird.orders，ape 5.8-1，使用 write.tree(digits=15) 导出并校验。原始来源：Sibley, C. G. 与 Ahlquist, J. E. (1990)，Phylogeny and Classification of Birds，Yale University Press，图 353。枝长为 DNA/DNA 杂交指标 Delta T50H，不是百万年。这是历史研究假说。
5：HIV-1 序列树（193 叶）来自 ape::hivtree.newick，ape 5.8-1，保留原 Newick 字符串。原始来源：Strimmer, K. 与 Pybus, O. G. (2001)，Exploring the demographic history of DNA sequences using the generalized skyline plot，Molecular Biology and Evolution 18:2298-2305。数据为刚果民主共和国采集的 HIV-1 group M 序列，保留原枝长，不另行推定时间单位。
6-12：平衡、梳状、多分叉、纯拓扑、表格及大树由 scripts/generate_modern_tree_examples.R 确定性生成的合成演示数据；节点名和枝长不代表实测数据或生物学推断。大树分别为 64 和 256 叶。

ape 数据许可：示例 4、5 按 GPL-2 分发（从 ape 的 GPL-2 | GPL-3 选项中选择）；保留 ape 作者及原始数据作者的署名。完整许可见随示例分发的 APE-DATA-GPL-2.txt。来源说明见 SOURCES.txt。

官方说明：ape 数据集手册；上游：ape 源码仓库。

全部示例随模块源码及 JAR 分发；打开导入窗口时，只补齐默认 config/bioData/example/modernTreeView/ 子目录中缺少的文件，已有文件直接读取并保留。运行时无需 R 或联网。每例的 VOICE 注释也指向该目录的来源说明。

右键菜单与安全编辑

查看子树、缩放、名称显隐、重命名和结构编辑以本次右键命中的节点为目标。右键已有选中节点或空白区域保留多选；左键空白区域清空选择。“选择后代”包含折叠后代，并可用于后续批量样式修改。

Delete clade 和 Detach node 必须先确认。对话框显示目标及其子树节点数、真实叶节点数，默认 Cancel；Enter、Esc 或关闭窗口均取消。根和最后剩余的叶不能删除。Delete clade 压缩非根单子父节点并累加枝长；Detach 保留单子父节点。两者均保留存活叶的根到叶距离。

折叠内部节点可单独展开或修改折叠属性。Add sibling and merge 将原入枝均分，保持原有叶节点距离。新标签页使用真实枝长的独立子树副本。

叶信息与样式导出

内部节点右键 Export leaf information 导出 UTF-8 TSV，包含折叠分支中的真实叶节点。字段为 name、real_branch_length、distance_from_clade_root、branch_color、branch_width、label_enabled。

距离不包含所选子树根的入枝；标签字段是节点自身设置，不代表当前视口可见性。默认使用 .tsv，也接受 .txt。保存路径会被记忆，覆盖已有文件须确认。

2. 输入参数

2.1 进化树输入方式

有三种方式可以输入进化树（按优先级排序）：

参数 说明
input.nwk.string 直接输入Newick格式字符串（优先级最高）
input.nwk.path Newick文件路径（.nwk, .newick, .tree）
input.tableLike.path 表格式树文件路径（ITP格式）

2.1.1 Newick字符串示例

类人猿进化树，分支长度为百万年前（MYA）：

(((Human:6.5,(Chimpanzee:1.5,Bonobo:1.5):5):2,Gorilla:8.5):4,Orangutan:12.5);

人类-黑猩猩: ~6.5 MYA, 黑猩猩-倭黑猩猩: ~1.5 MYA, 人类/黑猩猩-大猩猩: ~8.5 MYA, 人族-红毛猩猩: ~12.5 MYA

2.1.2 表格式格式示例

root:0    A:0.1,B:0.2
A:0.1     C:0.3,D:0.4
B:0.2
C:0.3
D:0.4

2.2 Newick格式标准

重要： Newick格式对节点名称有严格规定（依据 Wikipedia/PHYLIP 标准）。

2.2.1 语法规则

语法规则
Tree → Subtree ";" 树 必须 以分号结尾
Name → empty | string 节点名称可以为空或字符串
Length → empty | ":" number 分支长度跟在冒号后面

2.2.2 未引用名称中禁止使用的字符

字符 名称 原因
( )圆括号定义树结构
[ ]方括号注释（NHX格式）
'单引号字符串引用分隔符
:冒号分隔名称和长度
;分号树终止符
,逗号分隔兄弟节点
空格、制表符、换行符空白字符未引用名称中不允许

2.2.3 特殊规则

  • 下划线转换： 未引用字符串中的下划线（_）会被转换为空格
  • 引用规则： 使用单引号包含特殊字符的名称：'含空格的名称'
  • 引号转义： 引用字符串中的单引号用两个连续单引号表示：'it''s' → it's

2.2.4 节点名称转义示例

原始名称 Newick格式
abcabc
a b（含空格）a_b 或 'a b'
a_b（保留下划线）'a_b'
a (b'a (b'
a()[],;:'a()[],;:'
a'b（含引号）'a''b'
bacteria;archaea'bacteria;archaea'

2.2.5 参考资料

  • Wikipedia: Newick format
  • PHYLIP Newick 标准

2.3 Newick格式类型 (nwk.format)

默认值： 0 | 范围： 0-9

注意： Bootstrap支持度值应使用 0-100 范围（如：90），而非小数格式（0.9）。

格式 叶节点 内部节点 示例
0 名称:距离 支持度:距离 (A:0.1,(B:0.2,C:0.3)90:0.4);
1 名称:距离 名称:距离 (A:0.1,(B:0.2,C:0.3)NodeX:0.4);
2-3 格式0-1的严格版本（所有字段必填）
4 名称:距离 无 (A:0.1,(B:0.2,C:0.3));
5 名称:距离 仅:距离 (A:0.1,(B:0.2,C:0.3):0.4);
6 名称:距离 仅名称 (A:0.1,(B:0.2,C:0.3)NodeX);
7 仅名称 仅名称 (A,(B,C)NodeX);
8-9 仅名称(8) 或 无(9)

3. 高级参数

这些参数允许精细控制树的可视化效果。

3.1 树信息

参数 默认值 说明
tree.show.scale.bar F 显示绘图比例尺

3.4 根节点设置

参数 默认值 说明
