Pathway Family Browser

Visual browsing and interactive evolutionary analysis of biological pathways and multi-species gene copy numbers.

1. Quick Start

  1. Click Example to cycle through bundled presets (Example-1 to Example-6).
  2. Click Execute to load the phylogenetic tree and analysis tabs.
  3. Click any species node on the phylogenetic tree (or select a row in the Species Information table) to dynamically update copy-number overlays on the pathway diagram, component tables, and species traits.

2. Interactive Overview

The upper panel displays the phylogenetic tree, while the lower panel provides four synchronized analysis tabs:

  • Pathway Gallery: Accepts one or more pathway diagrams (.pptx, .svg, .png, .jpg). When $pathway.component.counts.path is provided and a species node is clicked on the tree, shapes matching pathway genes or categories are updated instantaneously:
    • Present Genes (Count ≥ 1): Rendered at full clarity with a copy-number badge at the top-right corner of the shape (blue badge for single-copy, orange-red highlight border and badge for multi-copy expansion).
    • Absent Genes (Count = 0): Automatically ghosted (faded to low opacity) to highlight lineage-specific gene loss.
    • Stage / Category Summaries: Shapes named after categories (e.g. cat1..cat9) dynamically display the summed gene copies for that stage in the selected species (Count: X).
  • Species Information: Sortable, filterable species table with bidirectional selection sync with the tree.
  • Pathway Components: Displays gene copy counts for the selected species. Supports both species-as-rows (Name column) and genes-as-rows (name + optional category + species columns, such as components.info.tsv).
  • Species Traits: Displays phenotypic or ecological traits for the selected tree node.

3. Setting Shape IDs in PPTX and XML Attributes in SVG

3.1 PowerPoint (.pptx) Shape Naming Convention

The first slide of each .pptx file is rendered. To link shapes to gene copy numbers or category totals, open PowerPoint and go to Home → Select → Selection Pane (shortcut Alt + F10), then set the shape names as follows:

Element Role Selection Pane Name Pattern Examples Interactive Behavior
Gene Shape / Box <GeneID>_comp or <GeneID>_comp<N>
(or exact <GeneID>)		 APC_comp, CTNNB1_comp, WNT_comp1, DVL_comp1 Matched to gene APC / CTNNB1 / WNT / DVL. Ghosted when count is explicitly 0; highlighted with a copy-number badge when count ≥ 1; displayed with a '?' badge when data is missing (NA/empty); unmapped shapes remain unaltered. Trailing * wildcard (e.g. WNT*_comp) aggregates family members.
Gene Label Text <GeneID>_name or <GeneID>_name<N> APC_name, CDC42_name, WNT_name1 Faded or kept crisp in sync with the corresponding <GeneID>_comp shape.
Stage / Category Slot <CategoryID> cat1, cat2, ..., cat9 Matched case-insensitively to the category column in components.info.tsv; displays Count: X for the selected species.
Background & Arrows Default PowerPoint names Rectangle 5, Connector 12 Rendered in exact presentation layer order (Z-order) for seamless visual stacking and sub-millisecond species switching.

Note: Gene matching is strictly exact (case-insensitive, e.g. WNT1 never matches WNT10A); use explicit * wildcard for family aggregation. PowerPoint group shapes (Ctrl+G) are recursively supported.

3.2 SVG (.svg) XML Attribute Convention

Vector pathway diagrams in .svg format can also be listed in $pathway.gallery.figure.paths. Set the id or data-gene attribute on SVG elements (<g>, <rect>, <circle>, <ellipse>, <path>, <text>):

<!-- Option 1: id="<GeneID>" or id="<GeneID>_<suffix>" -->
<g id="APC_comp">
    <rect x="120" y="80" width="60" height="28" fill="#89C65B"/>
    <text id="APC_name" x="150" y="98" text-anchor="middle">APC</text>
</g>

<!-- Option 2: data-gene="<GeneID>" -->
<g data-gene="CTNNB1">
    <ellipse cx="240" cy="160" rx="35" ry="18" fill="#5DADE2"/>
    <text x="240" y="165" text-anchor="middle">CTNNB1</text>
</g>

<!-- Category count slot: id="cat1" or data-category="cat1" -->
<rect id="cat1" x="40" y="30" width="110" height="26" fill="#3498DB"/>

4. Component Count Table Formats & Bundled Examples

$pathway.component.counts.path accepts UTF-8 TSV or the first sheet of an Excel workbook (.xlsx/.xls) in either orientation:

  1. Genes-as-rows (recommended, e.g. components.info.tsv in Example-1): Column 1 is name (gene ID), optional Column 2 is category (cat1..cat9), and remaining columns are species names matching tree leaves (e.g. Homo sapiens, Danio rerio).
  2. Species-as-rows (e.g. counts.tsv): Contains a Name column matching tree node names, with gene IDs as columns.

Select Example-1 through Example-6 in the import dialog: (1) Complete interactive Wnt workflow (9_model_species_evolution.nwk, components.info.tsv, wnt_pathway2.pptx, pathway_counts.pptx, demo_selection.pptx); (2) Glycolysis with Newick text; (3) Excel tables; (4) Multiple diagrams with table-tree input; (5) Partial coverage and zero counts; (6) 64-tip circular tree. Bundled files are automatically installed into config/bioData/pathwayBrowser/examples on first run without overwriting user-modified files.
