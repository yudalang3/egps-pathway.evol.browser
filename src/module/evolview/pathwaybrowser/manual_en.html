Pathway Browser

Visual browsing and interactive analysis of biological pathways.

1. Quick Start

  1. Click Example to see the input data
  2. Click Execute to see the results

2. Overview

Provides visualization browsing and interactive analysis of biological pathways. Supports pathway structure display, gene annotation, and pathway comparison.

Import and six offline examples

Select Example-1 through Example-6 in the import dialog, edit parameters and execute: complete Wnt workflow; glycolysis with Newick text; Excel tables; multiple diagrams with table-tree input; partial coverage; 64-tip circular tree.

Newick text takes priority over Newick files, then table trees. Canonical parameter names take priority over legacy aliases. Optional tables accept UTF-8 TSV or the first Excel sheet and require a Name column matching tree nodes. False disables optional panels. PPTX galleries display the first slide only and remain static when species are selected.

Bundled examples are installed under config/bioData/pathwayBrowser/examples. Existing user files are preserved; missing files are restored. All trees, lengths, counts and traits are teaching data, not research measurements. Human pathway images WP428 and WP534 come from WikiPathways under CC0. SOURCES.txt records download date, URLs, SHA256 checksums and conversion details.
