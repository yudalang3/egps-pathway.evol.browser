通路浏览器 (Pathway Family Browser)

生物学通路演化与多物种基因家族拷贝数的可视化浏览和交互式分析工具。

1. 快速开始

  1. 点击 示例 (Example) 切换或查看预设示例参数（Example-1 至 Example-6）。
  2. 点击 执行 (Execute) 加载系统发生树与下方通路分析面板。
  3. 使用鼠标左键点击系统树上的物种叶节点（或在物种信息表中选中某一行），下方通路图（Pathway Gallery）、物种信息、基因拷贝计数与性状表将实时联动更新。

2. 核心功能与交互联动

上方区域展示物种系统发生树，下方区域包含四个分析标签页：

  • Pathway Gallery（通路画廊）：支持导入多个通路图文件（.pptx、.svg、.png、.jpg）。当配置了 $pathway.component.counts.path 基因计数表并点击系统树上的物种节点时，通路图会根据形状 ID 与基因名称自动匹配：
    • 存在基因（Count ≥ 1）：保持清晰显示，并在组件右上角叠加基因拷贝数角标（单拷贝显示绿色角标，多拷贝显示橙红角标）。
    • 缺失基因（Count = 0）：该基因对应的形状与文字自动半透明淡化（Ghosting），直观呈现通路组分在特定物种中的丢失。
    • 通路阶段汇总（Category Counts）：若计数表包含 category 列（如 cat1..cat9），画布中对应 ID 的汇总框会自动更新该物种在该阶段的拷贝总数（Count: X）。
  • Species Information（物种信息）：展示物种分类、基因组与统计信息，支持搜索过滤及与系统树双向点击联动。
  • Pathway Components（通路组分计数）：展示当前选中物种在各个通路基因上的拷贝数。同时支持“物种为行（Name 列）”与“基因为行（name + category + 物种列，如 components.info.tsv）”两种表格格式。
  • Species Traits（物种性状）：展示当前选中物种的表型或生物学性状数据。

3. 如何在 PPTX 与 SVG 通路图中设置匹配 ID

3.1 PowerPoint (.pptx) 形状 ID 设置规范

本模块读取每个 .pptx 文件的第一页幻灯片。为了使通路图中的基因组件随物种点击动态显示拷贝数或阶段汇总，请在 PowerPoint 中打开 开始 (Home) → 选择 (Select) → 选择窗格 (Selection Pane)（快捷键 Alt + F10），按以下规则设置形状名称（Shape Name）：

元素类型 选择窗格命名规则 (Shape Name) 示例 交互效果说明
基因图形/背景框 <GeneID>_comp 或 <GeneID>_comp<N>
（或直接命名为 <GeneID>）		 APC_comp, CTNNB1_comp, WNT_comp1, DVL_comp1 匹配基因 APC / CTNNB1 / WNT / DVL；拷贝数显式为 0 时淡化为丢失，≥ 1 时绘制拷贝数角标与高亮外框；缺测（NA/空/?）时正常显示并标浅灰 ? 角标；未映射图形保持原样。若需对家族成员聚合求和可使用 * 通配符（如 WNT*_comp）。
基因名称文本框 <GeneID>_name 或 <GeneID>_name<N> APC_name, CDC42_name, WNT_name1 与对应 <GeneID>_comp 同步高亮或淡化，确保基因名称始终清晰可读。
阶段/类别计数框 <CategoryID> cat1, cat2, ..., cat9 匹配 components.info.tsv 中 category 列的分组名称（忽略大小写），动态替换为当前物种在该分组下的基因总拷贝数（如 Count: 25）。
背景与连接箭头 保留默认名称（如 椭圆 1、直线 2） Rectangle 5, Arrow 12 作为静态通路骨架按原始叠放顺序（Z-order）绘制，保证遮挡关系与毫秒级流畅响应。

提示：普通基因形状采用严格精确匹配（不区分大小写，如 WNT1 绝不会误匹配 WNT10A）；支持 PowerPoint 组合（Ctrl+G 编组内命名的组件可递归识别）。

3.2 SVG 矢量图 (.svg) 属性设置规范

除 .pptx 外，$pathway.gallery.figure.paths 还支持直接导入 .svg 矢量通路图。在 SVG 的 XML 标签（如 <g>、<rect>、<circle>、<ellipse>、<path>、<text>）上设置 id 或 data-gene 属性即可参与物种联动：

<!-- 方式 1：使用 id="<GeneID>" 或 id="<GeneID>_<suffix>" -->
<g id="APC_comp">
    <rect x="120" y="80" width="60" height="28" fill="#89C65B"/>
    <text id="APC_name" x="150" y="98" text-anchor="middle">APC</text>
</g>

<!-- 方式 2：使用自定义属性 data-gene="<GeneID>" -->
<g data-gene="CTNNB1">
    <ellipse cx="240" cy="160" rx="35" ry="18" fill="#5DADE2"/>
    <text x="240" y="165" text-anchor="middle">CTNNB1</text>
</g>

<!-- 阶段汇总槽位：使用 id="cat1" 或 data-category="cat1" -->
<rect id="cat1" x="40" y="30" width="110" height="26" fill="#3498DB"/>

4. 基因计数表格式与内置示例

$pathway.component.counts.path 支持 UTF-8 TSV 或 Excel (.xlsx/.xls) 首个工作表，兼容以下两种排布方式：

  1. 基因为行、物种为列（推荐，如 Example-1 的 components.info.tsv）：首列为 name（基因名，如 WNT1、APC、CTNNB1），可选第二列为 category（阶段分类，如 cat1..cat9），其余各列为物种名称（与系统树叶节点名称对应，如 Homo sapiens、Danio rerio）。
  2. 物种为行、基因为列（如 counts.tsv）：包含 Name 列（对应系统树节点名），其余各列为基因名，单元格为拷贝数。

在导入窗口可选择 Example-1 至 Example-6，依次为：Wnt 通路完整交互流程（包含 9_model_species_evolution.nwk、components.info.tsv 以及 wnt_pathway2.pptx、pathway_counts.pptx、demo_selection.pptx）、糖酵解（Newick 文本）、Excel 表格、多图画廊（表格树）、部分覆盖与零计数、64 叶环形树。示例文件在首次运行时自动生成到 config/bioData/pathwayBrowser/examples 目录；用户已修改的同名文件不会被覆盖，缺失文件会在打开导入窗口时自动补齐。

5. 缺测、名称匹配与文件准备

家族（例如 WNT*）、类别与底部 Copies 使用相同语义：全部已知时显示精确数字；存在缺测且已知和大于零时显示 ≥N（已知下界）；存在缺测且已知和为零时显示 ?，保持清晰。只有全部已知且为零才显示 0 并淡化。没有计数映射的图形保持原样。

名称匹配忽略大小写，统一空白、下划线和连字符；明确别名如 Human 对应 Homo sapiens。Xenopus tropicalis 与 Xenopus laevis 不互相替代。Frog、Xenopus 等泛称仅在候选唯一时匹配；多候选为歧义，不自动挑选。

Excel 公式由 Apache POI 实际求值；不支持或求值失败时停止导入，提示文件、工作表、行列与公式，不使用可能过期的缓存。可先在 Excel 中复制并“粘贴为值”，再保存导入。

导入时后台串行准备树、表格和全部通路图，进度条显示当前准备阶段。全部成功后统一替换；任意一张图失败保留原视图。PPTX 读取第一页，支持父组镜像、旋转及嵌套坐标。SVG 支持本地叶图元、组合及嵌套 use 引用和实例基因绑定；未绑定的引用保持静态。外部、循环或找不到的引用会报错。SVG 其余绘制能力取决于当前 JSVG，不等于浏览器支持的全部 SVG 特性。

通路导出仅针对已经就绪的完整缓存画布，与滚动位置、视口尺寸无关；未就绪时提示等待，不保存部分画面。模块或标签页关闭后取消对应后台任务，并忽略迟到回调。
