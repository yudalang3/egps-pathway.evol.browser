# Modern Tree View 右键菜单

本说明同样适用于复用树面板的 Gene family 和 Pathway browser。创作模式仍只在支持的矩形系统发生树布局中启用。

## 目标与选择

- 查看子树、缩放、名称显隐、重命名和结构编辑使用本次右键命中的节点。
- 右键已选中节点保留多选；右键未选中节点切换为该节点；右键空白处保留选择，左键空白处清空选择。
- “Select all descendant nodes”把目标节点及全部结构后代加入实际选择，包括折叠后代；随后可以批量调整颜色和线宽。
- “Set all descendant nodes unselected”只清除目标子树的选择及搜索高亮。空白处“Select descendants of marked nodes”同时接受直接选择和搜索高亮作为起点。
- 搜索高亮本身与实际选择保持独立；“Cancel all selections”清除两者。

## 编辑和确认

“Delete clade”和“Detach node”显示目标名称、子树节点数和真实叶节点数，折叠后代也计入。默认按钮为 Cancel；Enter、Esc、关闭窗口或点击 Cancel 均不执行删除。只有点击 Delete 后才修改树。

- 根节点不能删除；不允许删除最后剩余的叶节点。
- Detach 保留剩余的单子父节点；Delete clade 压缩非根单子父节点，把被压缩父枝长度加到剩余孩子的枝长上。
- 空祖先会被移除，避免形成虚假的叶节点；根节点始终保留，可以只剩一个孩子。
- Add sibling and merge 将目标原入枝均分为两段，并保持它在原父节点中的位置。新兄弟取半段枝长，原有叶节点的根到叶距离保持不变；零枝长保持为零。
- Add child 保留既有规则：对叶节点执行时，原叶变成内部节点并增加两个新叶；对内部节点执行时增加一个新叶。新叶名称显隐继承全局标签设置。
- 根节点没有兄弟；父节点只有一个孩子时不能交换兄弟。布局未就绪时禁用结构编辑和依赖坐标的动作。
- 每次结构编辑会刷新叶缓存、深度、大小和布局，并清理脱离树的选择、折叠属性及注释。存活节点的样式和注释保留。

## 折叠与显示

折叠的内部节点仍使用内部节点菜单，提供单独展开和折叠属性编辑。属性对话框回显当前颜色及三角形大小，取消颜色选择或取消对话框不改变树。全部展开后更新叶列表和深度缓存。

“Recover all graphics effects”恢复分支颜色、线宽、节点大小及字体，保留标签开关、折叠状态和注释。节点信息显示真实枝长；显示枝长不同时同时列出。新标签页中的子树使用真实枝长，副本根的入枝归零，不修改源树。

## 叶信息 TSV

内部节点的“Export leaf information”导出该子树中所有真实叶节点，包括折叠后代，顺序为树中的孩子顺序。

| 字段 | 含义 |
|---|---|
| `name` | 叶名称；空名称输出空字段 |
| `real_branch_length` | 真实末端枝长，不受 cladogram 等显示方式影响 |
| `distance_from_clade_root` | 从所选子树根到叶的真实距离，不包含子树根自身入枝 |
| `branch_color` | 分支颜色，`#RRGGBB` |
| `branch_width` | 分支线宽 |
| `label_enabled` | 节点自身的名称显示开关，`true` / `false` |

标签字段是节点设置，不表示是否被折叠、移出视口或被全局标签开关遮蔽。文件使用 UTF-8，包含表头；含制表符、换行或双引号的名称使用双引号引用，内部双引号重复转义。默认扩展名为 `.tsv`，也接受 `.txt`。

保存对话框记忆路径；覆盖已有文件前确认。导出使用独立快照，文件检查及写入在后台完成，失败时显示错误并记录日志。取消文件选择或覆盖确认不写文件。

## 验证

使用 JDK 25 或更新版本运行 `scripts/verify_tree_context_menus.ps1`；加 `-Gui` 验证实际的删除、折叠、重命名及注释对话框。测试代码位于 `src/test/`，日志位于 `logs/`，截图和临时文件位于 `temp/tree-context-menus/`。

导出失败测试会记录 `Expected test write failure`，这是主动注入的失败场景；最终通过与否以测试退出码和 passed 消息为准。图片导出、突变展示等历史隐藏入口及 Undo/Redo 不在本次修复范围。
