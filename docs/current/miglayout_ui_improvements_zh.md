# MigLayout UI 改进

## 目标

通过 `MigLayout`、边框和分隔线，让参数较多的面板更易读，不再显得拥挤。

## 已采用的模式

- 使用 `TitledBorder` 对配置区和输入区分组。
- 在逻辑块之间加入 `JSeparator`。
- 使用 `fill`、`grow`、`pushy` 让空白区域自然扩展，避免有效面板挤在中间。
- 统一主操作按钮文案，让 UI 读起来更一致。

## 常用约束

| 约束 | 作用 |
|------|------|
| `fill` | 让面板占满可用空间 |
| `insets 0` | 去掉外层额外留白 |
| `grow, fill` | 让列平滑扩展 |
| `grow, pushy` | 让某个分区吸收多余高度 |
| `growx, h 40!` | 让主操作按钮更醒目 |

## 结论

这一布局模式很适合同时包含文件选择器、单选组和单个运行按钮的模块面板。
