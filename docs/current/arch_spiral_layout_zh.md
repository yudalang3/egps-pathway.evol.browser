# 螺旋布局参考

## 概览

本文描述系统发育树可视化层当前使用的螺旋布局机制。

当前实现基于阿基米德螺线公式：

```text
r = alpha + beta * theta
```

其中：

- `r` 表示到布局中心的半径
- `alpha` 控制起始偏移
- `beta` 控制螺旋增长速度
- `theta` 表示弧度角

---

## 当前布局变体

当前代码中保留了两种螺旋变体。

### 基于 Alpha 的螺旋

这种变体让 `alpha` 变化，而 `beta` 保持固定。

**效果**

- 分支长度主要表现为径向偏移
- 各螺旋臂保持相同增长率
- 视觉上更接近同心式螺旋带

**适用场景**

- 分支长度差异较小的树
- 需要更容易阅读“平行轨迹”式螺旋布局的场景

### 基于 Beta 的螺旋

这种变体让 `beta` 变化，而 `alpha` 保持固定。

**效果**

- 分支长度主要表现为螺旋陡峭程度
- 不同分支向外增长的速度不同
- 视觉上更发散，更接近锥形展开

**适用场景**

- 分支长度差异较大的树
- 需要更强视觉分离度的场景

---

## 坐标计算

当前螺旋位置计算遵循下面这个模式：

```java
double radians = Math.toRadians(angleDeg);
double r = alpha + beta * radians;
double x = centerX + r * Math.cos(radians);
double y = centerY - r * Math.sin(radians);
```

`y` 上的负号是必须的，因为屏幕坐标系中 Y 轴是向下增长的。

## 比例尺与轴行为

螺旋布局在比例尺宽度计算上，会根据变化参数不同而采用不同规则。

### Alpha 模式

当 `alpha` 变化时，可见的径向差值基本是常量：

```text
delta_r = delta_alpha
```

因此比例尺宽度可以直接根据 alpha 的可用范围计算。

### Beta 模式

当 `beta` 变化时，可见的径向差值取决于外层角度：

```text
delta_r = delta_beta * theta
```

所以 beta 模式下不能把宽度视为常量，而要根据实际最大角度来计算。

## 当前配置面

当前螺旋布局使用的主要配置包括：

| 参数 | 含义 |
|------|------|
| `globalStartDegree` | 起始角度 |
| `globalExtendingDegree` | 总展开角度 |
| `gapSize` | 螺旋间距 |
| `betaFactor` | beta 模式使用的乘子 |
| `rootTipLength` | 最小根部视觉距离 |

---

## 实用建议

如果你希望螺旋结构更规整、距离比较更稳定，优先用 alpha 模式。

如果你希望较大的分支长度差异被更明显地拉开，优先用 beta 模式。

如果树规模不大，或者分支长度读数精度比紧凑展示更重要，非螺旋布局通常更清晰。
