# Pathway Browser 后续修复与验证

基线 bb1c133。本轮不修改依赖仓库，也不扩大 SVG/CSS、透明热区支持。

- PPTX 首次完整绘制通过 DrawFactory 捕获每个叶图元的 `DrawShape.getAnchor` 与实际 Graphics2D 变换。阶段框、角标和空间配对使用同一边界表；原公共矩阵方法保留兼容，主准备流程不再依赖其近似边界。
- 通路快照保存 PPTX 由本模块使用 POI 嵌入整幅 PNG；三参 SaveUtil 入口、目录记忆、文件选择、覆盖确认、取消和失败反馈保留。树与普通分析页继续使用原保存器。快照 PPTX 不提供原始矢量对象编辑能力。
- 主导出操作允许明确选择系统树或当前分析页；关闭所有通路子页时提示重新导入，未就绪时仍阻止保存。
- 取消时以取消后的版本号清理进度；旧清理不会覆盖新导入。Active 与 Copies 同步使用未知/下界语义。
- 路径禁用与归一化共享规则；挂载前检查图、表快照完整性，失败不修改控制器与旧视图。
- SVG 预检复用实际准备入口的尺寸、ID、引用检查；严格拒绝歧义 ID、无效引用和空动态切片。没有采用可能丢失一对多映射的 CSS 合并方案。
- 第零例静态引用改为在正确像素处断言；中文外框误述删除。日志保留磁盘产物但不再追踪；测试使用干净构建、资源复制、eGPS.args 与仅产物 classpath。

统一验收脚本：`pwsh -NoProfile -File scripts/test_pathway_remaining_fixes.ps1`。新增 FollowupGeometryTest 对比非等比父组与旋转子图元的真实绘制上下文和准备后的角标边界；FollowupExportTest 验证 PPTX 图片数量及读回渲染像素。原有 PNG、生命周期、示例与面板测试保留；生命周期测试补准备不完整、空白解析、取消以及立即重导入的进度断言。

机器结果：`logs/remaining-test-results.json`；实际临时样本及读回图在 `temp/review-export`、`temp/geometry-*.pptx`。非 PNG 其他格式不以“能写出文件”代替画面验收；复杂第三方效果及 CSS 性能优化仍未纳入本轮承诺。

## 最终验收

干净构建成功，13 套测试全部返回 0，六个示例工作流通过。几何新增测试包含 32 个镜像、非等比缩放、嵌套父组旋转与子图元自身旋转组合，断言准备后的角标边界与实际 POI 绘制上下文一致。PPTX 读回含 1 张图片，420×260，测试像素与原图一致。

完整回归前后的 tracked diff 哈希一致，记录于 `logs/followup-tracked-before.txt` 和 `logs/followup-tracked-after.txt`；日志保留在磁盘，不进入版本追踪。公开的无绘制上下文几何辅助方法保留旧兼容行为；精确叠加与配对已经全部切换到实际绘制边界表。
