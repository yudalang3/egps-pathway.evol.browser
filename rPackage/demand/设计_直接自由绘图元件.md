当从交互式的鼠标位置上获取你要的目标位置之后就可以添加绘图的元件了。



## 文字


这是用得最多的，我现在给予一个名称`free_text()`，这个自由就表示它可以随意添加。





比如有一张图

```r
y <- clust(dist) |> yytree(tree = .) + layout(code = 7)
y <- y + free_text(x = 4, y = 12 , mode = 'relative', locator = 'left', gap = 10)
# mode can be relative or pixel, default is relative
# locator can be left/right/center, default is left; gap is the left gap size 
print(y)
```

这样就可以直接在那里添加文字了





## ellipse （椭圆）
一个圆形，名称为`free_ellipse()`，顾名思义就是绘制椭圆和圆圈等形状。

```r
y <- clust(dist) |> yytree(tree = .) + layout(code = 7)
y <- y + free_ellipse(x = 4, y = 12 , width = 5, height = 5, fill_color = 'red', line_color = NA, line_thickness = 1, line_type = 'solid')
print(y)
```
