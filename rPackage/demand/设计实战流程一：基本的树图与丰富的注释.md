# 基础的

## 支持的树布局
首先确定布局，布局暂时规划如下：

| 布局 | 名称 | 编号（编程代码） | 说明 |
| --- | --- | --- | --- |
| 矩形布局 | rectangle | rect | 1 | 原始的聚类树 |
| 终端对齐的矩形布局 | rect_align | 2 | 为了美观，将叶子用虚线延长，得到终端对齐的树 |
| 环形布局 | circular | circ | 3 |  |
| 终端对齐的环形布局 | circ_align | 4 | 同矩形布局 |
| 拱形布局 | arch | 5 | |
| 终端对齐的拱形布局 | arch_align | 6 | 同矩形布局 |
| 倾斜布局 | slant | 7 | 是一个仅展示拓扑结构的`cladogram` |




后续的例子都用 **slant布局** 来做演示。

## 节点渲染（叶子和内节点）
```r

```

## 内节点到叶子的高亮块


`inner2leaf_highlight()`

也是通过两个叶子节点的 MRCA确定一个内节点，然后可以填充颜色

```r
y <- clust(dist) |> yytree(tree = ., layout = 7)
df_inner_render <- data.frame(name1 = c("Danio rerio"), name2 = c("Mus musculus"), fill = 'green')
# 这里是传入data.frame
y <- y + inner2leaf_highlight(df = df_inner_render)
print(y)
```

<!-- 这是一张图片，ocr 内容为：ARABIDOPSIS THALIANA ORYZA SATIVA SACCHAROMYCES CEREVISIAE CAENORHABDITIS ELEGANS DROSOPHILA MELANOGASTER DANIO RERIO XENOPUS HOMO SAPIENS MUS MUSCULUS -->
![](https://cdn.nlark.com/yuque/0/2026/png/21888953/1792763314624-790847f8-fbb5-4e34-8e49-c10d14309781.png)



也可以组合这个 `inner2leaf_highlight()`，从而得到

```r
y <- clust(dist) |> yytree(tree = ., layout = 7)
y <- y + inner2leaf_highlight(name1 = "Danio rerio", name2 = "Mus musculus", fill = 'red') + inner2leaf_highlight(name1 = "Xenopus", name2 = "Mus musculus", fill = 'yellow')
# 这样设置是所有的叶子节点都会改变
print(y)
```

这样就可以不断组合起来完成注释的目标。

## 具体语法设计
`leaf_annotation_*()`具体的函数形式就这样。以最简单的矩形块注释为例。

最后人们看到的结果就是一个热图的样子

最简单的矩形块：`leaf_annotation_rect()`

```r
y <- clust(dist) |> yytree(tree = .) + layout(code = 7)
y <- y + leaf_labels(show =T, align = 'right')
df_leaf_annotation_one <- data.frame(name = xxx, category1 = factor(xxx), category2 = factor(xxx))
y <- leaf_annotation_rect(df_leaf_annotation_one, legend = 'top_right')
print(y)
```

可以写成热图`leaf_annotation_heatmap()`

这样就能直接传入一个matrix了

```r
y <- clust(dist) |> yytree(tree = .) + layout(code = 7)
y <- y + leaf_labels(show =T, align = 'right')
df_leaf_annotation_one <- matrix(xxxx)
rownames(df_leaf_annotation_one) <- xxxx
colnames(df_leaf_annotation_one) <- xxx
y <- leaf_annotation_heatmap(df_leaf_annotation_one, legend = 'top_right')
print(y)
```



最重要的是两者可以组合，这样就可以多列注释了。
